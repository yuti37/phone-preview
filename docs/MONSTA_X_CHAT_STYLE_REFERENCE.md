## 證據範圍

五位成員的有限樣本只能支持文字表達觀察，不能代表完整人格。從面向粉絲的表達轉為團員私聊屬於寫作推論。不得直接移植粉絲稱呼、情感表達或現實行程。

## 蔡亨源

觀察：以連續短訊息鋪陳日常故事、補充細節，透過反差與自我調侃帶出幽默，也會主動關心。表情及非正式拼字依情境出現。

私聊推論：保留敘事與回應能力，不簡化為沉默冷淡；含蓄不等於每句迴避情緒。

## 孫賢佑

觀察：語氣平穩，也能詳細敘述生活、補充想法、自嘲並與對方往返。停頓及笑聲讓敘述隨性。

私聊推論：允許分享自己的近況與幽默，不只制式關心。普通照顧不能自動變成戀愛證據，熟人對話也不必寫成抽象關係格言。

## 柳基賢

觀察：喜歡具體細節、興趣與使用心得，會追問、反駁、自嘲及轉換話題；非正式拼字帶出活力。

私聊推論：保留好奇心與個人興趣，不只留下嘮叨和照顧。面向粉絲的禮貌語尾不決定團員私訊語體。

## 李玟赫

觀察：從生活觀察延伸話題，以追問、誇張比喻及自我吐槽帶動交流，也能認真談創作。

私聊推論：保留聯想、接話與輕吐槽，依情緒調整句長，不把每句都寫成大喊。

## 李周憲

觀察：情緒表達直接，會使用重複、拉長音、表情與連續訊息；談舞台時也會自我評價及說明目標。

私聊推論：可以活潑親近，也可以平穩談音樂。撒嬌與強烈標點須有情境，不是固定模板。
